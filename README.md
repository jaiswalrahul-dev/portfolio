# portfolio

## 概要
このプロジェクトは、Webエンジニアになることを目標に学習の一環として制作したPHPによるECサイトです。
HTML、CSS、JavaScript、を使用し、商品の一覧表示、商品詳細、ショッピングカートなど、ECサイトの基本機能を実装しました。

## 開発目的
- フロントエンドとバックエンドの連携を理解するため
- 実際のWebアプリケーション開発を経験するため
- GitHubを利用したソースコード管理を学ぶため

## 使用技術
- HTML5
- CSS3
- JavaScript

## 工夫した点
- シンプルで見やすいデザインを意識しました。
- ファイル構成を整理し、保守しやすいコードを心掛けました。
- HTML・CSS・JavaScriptを組み合わせて機能を実装しました。
- GitHubでソースコードを管理し、継続的に改善しています。

## 学んだこと
- HTML・CSSを使ったWebページ制作
- JavaScriptによる画面操作
- GitとGitHubを使ったバージョン管理
- Webアプリケーション開発の基本的な流れ
